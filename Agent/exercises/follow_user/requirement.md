# 自然语言需求

实现 `followUser(id1, id2)`：只有当两个用户均存在、二者不是同一用户，且 `id1`
尚未关注 `id2` 时，关注才能成功。

成功后必须同时满足：

1. `id1` 关注 `id2`；
2. `id2` 的粉丝中包含 `id1`。

异常检查顺序为：

1. `id1` 不存在；
2. 在 `id1` 存在的前提下，`id2` 不存在；
3. 两个用户都存在，但发生自我关注；
4. 两个用户都存在且不同，但关注关系已经存在。

异常发生时不得建立关注关系。本题已经给出行为分支、异常类型和 frame condition；
请填写各分支的条件及成功后的关系约束。
